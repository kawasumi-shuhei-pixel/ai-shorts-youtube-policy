プライバシーポリシー（ai-shorts 予約投稿）

制定日：2026年10月30日

1. この道具について

「ai-shorts 予約投稿」（以下「この道具」）は、YouTube チャンネルの持ち主が、自分で作った動画を自分のチャンネルに公開予約で上げるための個人用の道具です。持ち主のパソコンの中だけで動き、持ち主以外の人は使えません。

2. 使う情報

この道具は、持ち主が Google アカウントで許可したときに限り、YouTube Data API を通じて次の情報を扱います。

  • 持ち主のチャンネルの ID と名前（上げる先を取り違えないための確認）
  • 持ち主のチャンネルの動画の題名・公開の状態・公開予定の日時（同じ日に2本出さないための確認）
  • 持ち主が用意した動画ファイルと、その題名・説明・タグ・カテゴリ・言語・公開予定の日時などの設定（YouTube に上げるため）

求める権限は「動画のアップロード（youtube.upload）」と「自分のチャンネルの読み取り（youtube.readonly）」だけです。

3. 情報の保存と共有

  • 許可の情報（アクセストークン・更新用トークンなどの OAuth の認証情報）は、持ち主のパソコンの中にだけ保存します。持ち主がそのファイルを消すか、下の5章で許可を取り消すまで残ります。
  • この道具の作り手が運営するサーバーはありません。情報の送り先は、動画を上げて状態を確かめるための Google（YouTube）だけです。
  • Google（YouTube）を除く第三者に、受け取った情報を渡したり、売ったり、広告に使ったりしません。

4. Google のポリシーへの準拠

この道具が Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 許可の取り消し

許可は、Google アカウントの サードパーティとの接続の管理 からいつでも取り消せます。取り消すと、この道具は YouTube に繋がらなくなります。

6. 変更

このポリシーを変えるときは、このページを書き換え、制定日の下に変更日を書きます。
